Aplicaciones de proceso

Procesos entregados como aplicaciones reales.

Una aplicación cubre un área de trabajo completa: los procesos sobre un modelo de datos compartido, con los formularios, tareas, pantallas y reglas que les corresponden.

Las aplicaciones de proceso son la forma en que el trabajo realmente se realiza en Datapolis.
En lugar de diseñar pantallas primero, defines los procesos — y la aplicación surge de ellos, junto con los datos, pantallas, roles y permisos que necesitan.
Cada tarea, formulario, lista y decisión siempre está conectada con la lógica del proceso detrás de ella.

  • Tantos procesos como necesite el área — en una sola aplicación
  • Un modelo de datos compartido por todos ellos
  • Pantallas, roles, permisos y reglas definidos una vez, para toda la app
  • Construidas para humanos y trabajadores digitales

Qué hace una aplicación de proceso

UI impulsada por el proceso

Las pantallas no se diseñan en aislamiento.
El proceso define lo que los usuarios ven, cuándo lo ven y qué acciones están permitidas.

Lógica y reglas integradas

Validaciones, enrutamiento, permisos y aprobaciones provienen del workflow — no de una lógica UI codificada.

Una app, muchos roles

La misma aplicación de proceso se adapta a usuarios, roles y estados — sin crear versiones separadas.
